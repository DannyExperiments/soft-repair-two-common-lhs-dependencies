# Repair choices in the four-block example

Extract the ZIP and open index.html locally. Select one of three repairs or toggle any individual fact. Drag sideways or focus the figure and use the arrow keys. The labeled boxes are C values grouped by the B block. All facts have the same A value.

The triangle blocks retain six facts and cost 2,828. Three full blocks that include the isolated block give 2,830 when they retain only one shared edge label. The illustrated partial choice costs 2,952. The links join equal C labels, which escape the C penalty. Any pair with both B and C disagreements pays both penalties.

Use Python 3.11 or newer and Pillow 10.1 or newer. Run python3 visualization/render.py from the repository root to rebuild the looping GIF and the offline ZIP.
