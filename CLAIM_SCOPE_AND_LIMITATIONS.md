# Scope and limitations

The relation schema R(A,B,C) and dependencies A→B and A→C are fixed. Numerical weights are input, with polynomially bounded integer choices in the reduction. All facts have the same A value and common positive deletion weight, and the A→C penalty is one. The separately counted violations charge every dependency violated by a retained unordered pair.

The theorem classifies this fixed dependency set for the supplied-weight objective. A setting with all weights fixed constants and the other open dependency sets in the source remain separate questions. The replay tests finite instances. External peer review, formal verification and an exhaustive priority search remain pending.
